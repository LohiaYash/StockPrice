# Stock Price Prediction

A machine learning-based stock price prediction application using LSTM and Streamlit.

## 🚀 Live Demo

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://lohiayash-stockprice-webviewapp-dvns84.streamlit.app/)

## 📂 Project Structure

- Model/ - Trained machine learning model and scaler.
- WebView/ - Streamlit web application.
- StockPrice.ipynb - Model development and training.

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Yahoo Finance API
- Streamlit

## 📊 Features

- Historical stock data retrieval
- LSTM-based stock price prediction
- Latest closing price
- Interactive web interface
